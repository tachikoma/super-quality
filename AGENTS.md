## COMMANDS
```bash
# Install dependencies
uv sync

# Run backtest (default output to ./outputs)
uv run super-quality run

# Run with custom dates and output dir
uv run super-quality run --start 2015-01-01 --end 2024-12-31 --output my_results

# Run tests
pytest -v

# Lint
ruff check
```

## NOTES
- The `.env` file must contain `DART_API_KEY` for financial data access.
- All output files are written to the `outputs/` directory unless overridden.
- The internal `.omo/` directory stores agent plans and should be ignored by production code.
